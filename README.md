# Automatic Door System

## Project Description
This project is an Automatic Door System developed using Arduino.

## Components Used
- Arduino Uno
- Servo Motor
- IR Sensor
- Led

## Features
- Detects a person using an ultrasonic sensor.
- Opens the door automatically.
- Closes the door after a few seconds.

Developed using an online simulation platform.
